Static vs dynamic QR codes — an honest word

Static codes (what this page makes)

  • The content is baked into the pattern — works forever, free.
  • No account, no middleman, no subscription holding your code hostage.
  • Cannot be edited after printing, and scans can't be tracked.
  • Best for: menus, Wi-Fi, weddings, business cards, packaging, signs.

Dynamic codes (paid services)

  • The code points to a short redirect link the service controls.
  • Destination can be edited later and scans can be counted.
  • The code stops working if the subscription lapses — a real risk for print that stays up for years.
  • Best for: short campaigns where scan analytics matter more than permanence.

Most small businesses and events are better served by a static code plus a link they control themselves — a menu page you can edit gives you the flexibility of dynamic without the monthly bill or the expiry risk.

QR code questions, answered

Is this QR code maker really free?+
Yes. Every feature is free — all QR types, colours, dot styles, logo embedding, scan testing and high-resolution PNG and SVG downloads. There is no sign-up, no watermark and no limit on how many codes you create.
Do these QR codes expire?+
No. These are static codes: your link, Wi-Fi password or contact details are encoded directly into the pattern, so the code works forever. A menu code works as long as the menu page exists; a Wi-Fi code works until you change the router password.
What is the difference between static and dynamic QR codes?+
A static code stores the actual content inside the pattern — it can't be edited after printing, but it never expires and needs no middleman. A dynamic code stores a short redirect link owned by a paid service, so the destination can be edited and scans tracked — but the code dies if the subscription lapses. For menus, Wi-Fi, weddings and business cards, static is the reliable choice.
Can I put my logo in the middle of the QR code?+
Yes — upload your logo and it sits in the centre with high error correction, which lets the code tolerate the covered area. Keep the logo modest (the tool caps its size) and always run the scan test before printing hundreds of copies.
What size should I print my QR code?+
For close-range scanning — table cards, packaging, business cards — print at least 2 × 2 cm. A good rule: print size ≈ scanning distance ÷ 10, so a poster scanned from a metre away needs a code at least 10 cm wide. Download the 2048px PNG for large prints.
Why won't my QR code scan?+
The usual causes: low contrast between dots and background, printing too small, a logo covering too much of the code, or glare on glossy paper. Use dark dots on a light background, watch the contrast warning under the preview, and run the scan test on this page.
Is my Wi-Fi password safe in a QR code?+
The password is encoded inside the code itself — anyone who scans it joins your network, so display the card where guests are welcome. The code is generated entirely in your browser: your password is never uploaded or sent to any server.
Can I use these QR codes for my business?+
Yes. Codes you create here are yours to use commercially — menus, packaging, shop windows, flyers, business cards and anywhere else — with no attribution required.
Can I scan a QR code from a screenshot or photo?+
Yes — most modern phones can read a code straight from an image. On iPhone, open the screenshot in Photos and press and hold the code; on Android, open it in Google Photos and tap Lens, or use your gallery app's built-in scanner. The code just needs to be sharp and fully in frame — a blurry, tilted or cropped screenshot may not decode.
Do guests need an app to scan a Wi-Fi QR code?+
No. Any recent iPhone or Android phone reads Wi-Fi codes with its built-in camera: point it at the code, tap the banner that appears, and the phone joins the network — no app to install, no password to type. On older phones, the camera's QR mode or Google Lens does the same job.
Can I change where a printed QR code points?+
No — with a static code the destination is baked into the pattern itself, so it can't be changed after printing; to point somewhere else you generate a new code and print that instead. The one workaround: if the code links to a page you control, like your online menu, you can change what's on that page and the printed code keeps working unchanged.
Can I see how many people scanned my QR code?+
Not from the code itself — a static code reports nothing back, which is also why it never expires. If counts matter, point the code at a page you control: your website analytics, or a link shortener with click stats, will show the visits that arrive from scans.
Can I make a QR code for a PDF or a file?+
Yes — but a static QR code holds a link, not the file itself. Upload the PDF to a stable hosting link first (your website, or a share link from your file storage), then point the code at that link using the Website / URL tab. Test the link on a phone before you print, so you know scanners land on the file, not a sign-in page.
